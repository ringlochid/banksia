# Context access

Begin by calling `get_current_context` once for coherent current controller truth. Use its allowed actions, capabilities, live workflow neighborhood, Assignment files, and exact trigger rather than inferring currentness from provider history or nearby files. Its readback refs are relative to `.banksia/<task_id>/`. If the optional current fields are null or the request readback is needed for exact continuation detail, read `.banksia/<task_id>/<readback_refs.input>` with the provider's native filesystem access.

Use the provider's native filesystem tools for workspace files and loose Task notes or artifacts. Controller-owned Node tools do not proxy generic file listing or reads.

Read only the named refs needed for the current decision. Support projections are readable aids, not controller authority, and a missing support projection does not change dispatch legality.
